PCFF/Class2 M2 reference summaries derived from the M1 LAMMPS golden corpus.

Format:
- `energy <name> <value>` uses LAMMPS `units real` energy units (`kcal/mol`).
- `force <atom_id> <fx> <fy> <fz>` uses LAMMPS force units (`kcal/mol/angstrom`).

These files intentionally store only the observables used by the CPU regression tests.
