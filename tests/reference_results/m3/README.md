# M3 reference summaries

Format:

- `energy <name> <value>` uses LAMMPS `real` energy units (`kcal/mol`).
- `force <atom_id> <fx> <fy> <fz>` uses LAMMPS force units (`kcal/mol/angstrom`).

These summaries are frozen from the staged `dihedral_toy` LAMMPS outputs used for the M3 CPU Class2 dihedral validation.
