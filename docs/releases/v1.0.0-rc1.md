# Release Notes: v1.0.0-rc1

## Overview
This release candidate (`v1.0.0-rc1`) marks the completion of the foundational validation phase for the GROMACS-PCFF bridge. It establishes high-fidelity force field parity and ensemble-level statistical consistency for supported PCFF chemistries.

## Validated Scope
- **Topology/Force-Field Bridge:** Verified deterministic rule-based typing and parameter assignment.
- **Engine Parity:** Demonstrated near-identical energy and force profiles between GROMACS and LAMMPS for bonded, non-bonded (LJ 9-6), and combined systems.
- **Ensemble Stability:** Validated NPT behavior for medium-scale systems (0.1 ns production).

## Readiness Matrix Summary
| System Class | Readiness Status | Key Evidence |
| :--- | :--- | :--- |
| **Neutral Dense/Liquid** | **Production-Ready** | Sub-1% density parity, ~2% PE parity (M10.3) |
| **Charged/Salt** | **Qualified-Ready** | Sub-0.1% PE parity; Requires manual monitoring (M10.4) |
| **Transport Properties** | **Out-of-Scope** | Not yet validated for rc1 |

## Key Caveats
- **Charged System Density:** Significant density discrepancies (~55%) observed in small ionic boxes due to PME/PPPM virial differences. High-charge systems require manual volume relaxation review.
- **Chemistry Limits:** Limited to supported PCFF functional groups present in the `lammps_golden` validation corpus.
